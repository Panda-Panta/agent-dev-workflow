## 文件类别、输出与保留

映射现有目录，不要求新建下面所有类别。源码/资源、文档、长期脚本、构建中间结果、最终交付包、验证报告、任务试验、缓存和备份按实际用途分开；同类内容多时再按模块、任务或版本分组。小项目可用少量目录，最终交付与临时内容仍应区分。

工具代码放 scripts/tools 等工具目录，详细说明放 docs/references 等文档目录，索引将两者链接到各自唯一维护入口。根导航、工程配置、短帮助及工具包局部 README 可就近，长篇正文不重复。任务试验中的脚本、文档记录和输出分开；既有混放仅在本次范围内检查调用与链接后逐步调整，不为目录整齐全库迁移。
