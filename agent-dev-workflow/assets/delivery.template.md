## 每次交付的证据

个人小任务可合为一条结果记录，只填写适用环节。纯文档/知识更新且程序与分发内容不变时，核验文档和实际同步位置即可，不重建或安装相同程序。

- 任务 ID、test 候选 SHA、实际验证命令/结果与证据；无 Git 时填实际版本：
- main 实际 SHA、PR 或直接合入方式与结果；适用审查/CI 证据：
- 制品来源提交/版本、正式交付时与 main 的对应依据；产物路径、大小及 SHA-256：
- 远端 test/main 实际 SHA 与同步状态；未同步原因：
- 软件目录用途、安装来源与执行人、安装后文件校验/版本及运行结果：
- 用户数据保留、备份校验与必要的恢复结果：
- 包内清单核验、实际清理清单、仍保留的产物及原因：
- 部分完成、失败或未验证环节及下一动作：

远端、安装文件和运行分别记实；事后文档提交与制品来源提交分开记录。源码内容影响制品时重建，不为补交付记录重建相同程序。
