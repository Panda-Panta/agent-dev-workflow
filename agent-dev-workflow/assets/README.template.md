## 文档入口

已验证的可复用操作流程优先补到现有说明；复杂、稳定且易错的流程链接对应领域 skill。正文按需写清适用范围、工具真实调用、环境准备、执行与结束步骤、输出验证、恢复和限制；基于实际证据，易变参数注明获取方式。小流程几行即可，不强制新建文件，日志只记录本次事实并链接这里；未完成或未验证内容放交接草稿，不能写成成功步骤。

## 开发者入口（按需）
